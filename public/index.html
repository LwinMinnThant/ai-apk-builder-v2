🤖 AI APK Builder

Prompt → AI App → Preview → APK Build Request

Server ကို စစ်ဆေးနေသည်…

APK Build ခလုတ်သည် AI က HTML app ဖန်တီးပြီး GitHub Actions ထံ APK Build အလုပ်ကို ပို့ပေးသည်။ Build ပြီးမှ Actions ရဲ့ Artifacts မှ APK ကို Download လုပ်ပါ။

အရေးကြီး

APK auto-build အတွက် backend ပေါ်မှာ Gemini API Key နဲ့ GitHub repo token/configuration ထည့်ထားဖို့ လိုပါတယ်။ ဒီ starter က AI ထုတ်ပေးတဲ့ HTML prototype ကို Android WebView app အဖြစ် package လုပ်ပေးတာဖြစ်ပြီး native Kotlin/Java app အားလုံးကို အလိုအလျောက်ပြောင်းပေးနိုင်တဲ့ universal compiler မဟုတ်သေးပါ။

API Key / GitHub Token ကို browser code ထဲ မထည့်ပါနှင့်။ Backend environment variables မှာသာ ထည့်ပါ။
